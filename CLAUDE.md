# AIPulse Website

## Project Overview

Marketing website for AIPulse — AI training company for SMBs and sole proprietors (MŚP/JDG, Polish market). Currently a Vite static site (HTML/JS/CSS), planned evolution to full web presence.

**GitHub:** https://github.com/AiPulseInc/aipulse-webpage (private, main branch)
**Local path:** `/Users/mk/code-sandbox/toolbox-project/aipulse-webpage`

## Commands

```
npm install   # Install Vite
npm run dev   # Vite dev server
npm run build # Production build
```

## Tech Stack (current)

Vite 5, vanilla JS (ES modules), CSS (custom), Google Fonts (Inter, Outfit, Space Grotesk). No framework yet.

## Structure

```
index.html    -- Entry point (theme: neon-nexus)
main.js       -- App logic (ES module)
style.css     -- Styles
assets/       -- Static assets
images/       -- Image resources
```
